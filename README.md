# Salabintana Decoration — Website Dekorasi Wedding 💐

Landing page untuk usaha dekorasi pernikahan **Salabintana Decoration** (Bandung), menampilkan galeri portofolio dekorasi dan informasi kontak untuk calon klien.

## ✨ Fitur

- Galeri foto dekorasi pernikahan yang responsif
- Desain elegan dengan aksen warna gold & hijau
- Landing page siap pakai untuk kebutuhan promosi bisnis UMKM

## 🛠️ Dibangun dengan

- HTML, CSS, dan JavaScript murni (tanpa framework)

## 🚀 Cara menjalankan

1. Clone repo ini
2. Buka `index.html` langsung di browser, **atau**
3. Jalankan lewat VS Code Live Server untuk development

## 📁 Struktur proyek

```
index.html   -> halaman utama (hero, galeri, kontak)
css/         -> styling halaman
js/          -> interaksi (mis. galeri/slider)
images/      -> dokumentasi hasil dekorasi & aset visual
```

## 🎯 Konteks

Dibuat sebagai project freelance/portofolio untuk usaha dekorasi pernikahan lokal, menunjukkan kemampuan membangun landing page bisnis dari brief nyata.
